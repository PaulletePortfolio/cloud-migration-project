# cloud-migration-project

Project Scenario: *Company: Luxes Event Venue*

Luxes Event Venue is a fictional company that has been operating for four years, providing a luxury venue for weddings, graduation ceremonies, birthday parties, corporate events, and other special occasions.

Currently, the company manages most of its operations using paper-based documentation, including client contracts, booking forms, invoices, and event schedules. This manual process makes it difficult to organize information, increases the risk of losing important documents, and can lead to booking conflicts and communication issues between staff.
